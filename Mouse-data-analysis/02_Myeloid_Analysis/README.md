# Module 02 — Myeloid Subcluster Analysis

## What this step does
Subsets myeloid cells from the global object, re-clusters them at higher resolution, annotates 11 myeloid subtypes, and generates the combined panel used as Fig. S3 (`Extended_Fig7_combined.svg`).

## Input
| File | Description |
|---|---|
| `../../01_Global_Analysis/objects/global_clustered_annotated.rds` | Output of Module 01 |

## Key Analysis Steps
1. Subset to Myeloid cells (from `major_celltype` column)
2. Re-normalize, find variable features (n=3000), scale (regress `percent.mt`), PCA (30 PCs)
3. Cluster at resolution 0.3 using 20 PCs → 13 raw clusters
4. `FindAllMarkers` on all 13 clusters for marker gene identification
5. Remove contamination clusters: `9` (B-cell/high-mito), `11` (T-cell doublet)
6. Annotate remaining 11 clusters with `celltype_short` labels

## Key Parameters
- PCA dims: 1:20
- Clustering resolution: 0.3
- UMAP reduction name: `umap.pca_myeloid`
- Heatmap gene set: ~100 canonical myeloid marker genes
- Heatmap z-score clipped: `[-1.5, 2]`

## Color palette
Subtype colors are generated by `RColorBrewer::brewer.pal(11, "Set3")` over the 11 annotated subtypes and used consistently in the UMAP, pies and heatmap annotation.

## Figure Layout: Extended_Fig7_combined.svg
- Dimensions: 16 × 20 in, 600 dpi, SVG only
- **Panel A:** Annotated UMAP, no legend (legend in pie panel)
- **Panel B:** Pie charts in 2×2 grid (BAS/PD top, REC/RCU bottom), shared legend at bottom
- **Panel C:** pheatmap — average expression z-scored per gene, clusters (rows) and genes (columns) hierarchically clustered, row annotation = subtype + n cells
- Layout: `top_row / heatmap`, heights `c(1.3, 2)`
