# Single-cell RNA and TCR sequencing of gingival T cells in recurrent periodontitis

Analysis code for Sharma et al. (2026), *Clonally Convergent Tph/Tfh-like CD4+ T Cells are Shared Across Recovery and Recurrence in Experimental Periodontitis*. Gingival immune cells from the Sensitized Recurrent Periodontitis (SeRPD) mouse model were profiled by 10x Genomics 5′ single-cell RNA-seq with paired V(D)J sequencing at four phases: baseline (BAS), periodontitis (PD), recovery (REC) and recurrence (RCU), two independent sample pools per phase. A public human gingival dataset (GSE164241) is used for cross-species comparison.

## Repository layout

Paper modules run in numeric order; each reads only the outputs of earlier modules.

```text
.
├── 01_Global_Analysis/            # global clustering + annotation (T, B, myeloid, stromal)
├── 02_Myeloid_Analysis/           # myeloid sub-clustering (11 subsets)
├── 03_Tcell_Analysis/             # T-cell cleanup, TCR chain classification, αβ T-cell clustering + annotation
├── 04_Tcell_Expansion_Analysis/   # clonotype size and clonal expansion
├── 05_TCR_Repertoire_Analysis/    # TCRβ V–J usage, β-gene prevalence/Jaccard, shared/convergent clonotypes, TCR dropout
├── 06_CrossSpecies_Tph/           # mouse Tfh/Tph-like vs human Tph-like (C9): B-helper module + cross-species tests
├── Human/                         # human inputs to module 06 (made by ../Human-data-analysis): final object, marker table, gene table
├── run_all.sh                     # runs everything in dependency order
├── renv.lock                      # exact R + package versions
└── README.md
```

Every module folder has the same structure: `scripts/` (code), `objects/` (tables and Seurat objects written by the scripts), `figures/` (SVGs), `results/` (session info and run logs). Each module's `README.md` lists its scripts, inputs and outputs.

## Data

Two input objects are required; both are deposited at Zenodo **[DOI]** (raw sequencing data: GEO [GSE350875](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE350875)).

| File | Place it in | Description |
|---|---|---|
| `rivas_3111_integrated_scrna_tcr.rds` | `01_Global_Analysis/objects/` | Mouse gene expression + TCR, 8 samples, 51,572 cells after QC, CCA-integrated, TCR metadata added with scRepertoire `combineExpression` |
| `tcell_final_seurat_object.rds` | `Human/` | Annotated human T cells from GSE164241 (20,802 cells, C1–C9) |

All other objects are regenerated by the pipeline. Upstream steps that produced the mouse input (Cell Ranger multi v9.0.0, QC, scRepertoire v2.5.0 and Seurat v5.0.3 in R 4.4.2; see the manuscript's Materials and Methods) are not part of this repository. The human input is produced by [`../Human-data-analysis`](../Human-data-analysis).

## Reproducing the analysis

Requirements: R 4.5.1 and the packages pinned in `renv.lock` (CRAN + Bioconductor 3.22; Seurat 5.4.0, scRepertoire 2.6.2).

```r
# from the repository root, in R
install.packages("renv")
renv::restore()        # installs the exact package versions from renv.lock
```

```bash
./run_all.sh               # all modules, 01–06
./run_all.sh 05 06         # selected modules only (their inputs must already exist)
```

`run_all.sh` runs each script from its own `scripts/` directory (all paths in the scripts are relative to it) and writes a log per script to `<module>/results/logs/`. A full run takes about 15 minutes on an Apple-silicon laptop. Scripts can also be run one at a time with `Rscript <script>.R` from inside the module's `scripts/` folder, in the order listed in each module README.

All random steps are seeded, and two consecutive full runs gave identical outputs. Rerunning the pipeline from the two input objects (Module 03 reclustering from scratch, `start_from_clustered <- FALSE`) reproduced the original analysis: 101 of the 103 output tables of the paper modules are identical value-for-value; the other two differ only in the cluster-6 label (an earlier diagnostic written before the relabel) and in the doublet check, now produced by `Tcell_doublet_check.R` (mixed-Trm cluster 1.2% vs 1.3% originally, still the lowest of any cluster).

**Note for macOS:** `renv.lock` pins `scran` 1.38.0, whose macOS binary is no longer on Bioconductor 3.22 (now 1.38.1), so `renv::restore()` builds it from source. This needs the CRAN macOS toolchain (Xcode command-line tools + gfortran 14.2 from https://mac.r-project.org/tools/). `scran` is only needed by `scDblFinder` (Module 03 doublet check).
