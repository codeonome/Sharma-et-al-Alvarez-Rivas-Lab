# Published results — human GSE164241 reanalysis

These are the tables and figures reported in the manuscript, kept exactly as produced by the original analysis. The pipeline in the parent folder regenerates every table here byte for byte; `verify/verify_outputs.R` checks against this folder.

| Folder | Pipeline steps | Contents |
|---|---|---|
| `01_Global_Analysis/` | 02, 03 | global resolution sweep flags, global res-0.1 markers, global UMAPs |
| `02_Immune_Subset/` | 03 | immune re-clustering: markers, marker panels, UMAPs, resolution sweep |
| `03_Tcell_Reclustering/` | 04, 05 | T-cell re-clustering: markers, panels, UMAPs, sweep; validation of clusters 3, 8 and 9 |
| `04_Tcell_Final/` | 06–09 | cleanup, C1–C9 composition, differential abundance (primary: `DA_propeller_donor_blocked.csv`), pseudobulk DE, final figures |
| `05_CrossSpecies_Tph/` | — | curated human–mouse Tph gene table (used by `Mouse-data-analysis/06_CrossSpecies_Tph`) |

Notes:
- **Seurat objects (`.rds`) are not in git.** They are deposited separately.
- **Two figures are omitted because they exceed GitHub's 100 MB file limit:** `02_Immune_Subset/figures/umap_immune_unintegrated_by_sample.svg` and `umap_immune_harmony_by_sample.svg`. The PNG of the unintegrated version is included. Both are regenerated by pipeline step 03.
- **Format:** where a figure existed as both PNG and SVG, only the SVG is kept.
- **Supplementary Table 1:** `04_Tcell_Final/results/Propeller_DA_results.xlsx`. It is assembled by hand from `DA_propeller_donor_blocked.csv` (primary model) and `DA_all_tests_wide.csv` (sample- and donor-level models), which step 07 regenerates exactly.
